# .kuza-smoke

Небольшой сайт на Kuza 0.5.0: счётчик, текст, ссылка на документацию и Tailwind-классы прямо в `main.kuza`.

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # dist/index.html
```

Измени `main.kuza` — экран `view App<> >> [...]` обновится сам, ручной `draw<>()` больше не нужен.
